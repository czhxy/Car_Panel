# VOFA+ PID 调参指南 — 动力域 ECU

---

## 1. VOFA+ 配置

### 连接设置

| 参数 | 值 |
|---|---|
| 协议 | FireWater |
| 波特率 | 115200 |
| 数据位 | 8 |
| 校验 | 无 |
| 停止位 | 1 |

### 波形通道定义

| 通道 | 名称 | 含义 | 单位 |
|---|---|---|---|
| CH1 | Target | 目标转速 | rpm |
| CH2 | Speed | 实测转速 | rpm |
| CH3 | PID Out | PID 控制器输出 | -999~+999 |
| CH4 | Error | 转速误差（目标−实测） | rpm |

**建议 Y 轴分区**：将 CH1/CH2/CH4 归入左轴（转速，范围自动），CH3 归入右轴（PWM 占空比，固定 ±1000）。这样两条转速曲线可叠加对比。

## 4. 调参流程（Ziegler-Nichols 方法适配）

### 第一步：临界比例度法找 Ku、Tu

1. 点击 `vofa l on`，观察波形窗口出现 4 条曲线
2. 点击 `pid l ki 0` + `pid l kd 0`（关掉 I、D 项，纯 P 控制）
3. 点击 `motor l 100`，观察两条转速曲线
4. 逐步点击增大 Kp（0.5 → 1.0 → 2.0 → 5.0 → ...），每次点完等待 1-2 秒看波形
5. **当目标/实测曲线出现等幅振荡（不衰减也不发散）时，记录：**
   - **Ku** = 当前 Kp 值（临界增益）
   - **Tu** = 振荡周期（秒，在 VOFA+ 时间轴上量两个波峰间距）

### 第二步：查表计算 PID 参数

| 控制器 | Kp | Ki | Kd |
|---|---|---|---|
| P | 0.5 × Ku | 0 | 0 |
| PI | 0.45 × Ku | Kp / (0.83 × Tu) | 0 |
| PID | 0.6 × Ku | Kp / (0.5 × Tu) | Kp × (0.125 × Tu) |

**示例**：
- 假设测得 Ku=3.0, Tu=0.2s
- PID 参数：Kp=1.8, Ki=18.0, Kd=0.045
- 点击 `pid l kp 1.8`、`pid l ki 18.0`、`pid l kd 0.045`

### 第三步：微调验证

1. 点击 `motor l 100`，观察阶跃响应
2. 点击 `motor l -50`，观察反向响应
3. 点击 `motor l 300`，观察大目标响应
4. 点击 `motor l stop`，观察刹车波形

**微调方向**：
- 上升慢 → 加大 Kp
- 超调大 → 减小 Kp 或加大 Kd
- 稳态有偏差 → 加大 Ki
- 振荡不衰减 → 增大 Ki 的同时减小 Kp

### 第四步：右电机重复

点击 `vofa r on`，重复第一步~第三步。

## 5. 预期波形现象

### 理想的阶跃响应波形

```
转速(rpm)
  ^
  |    Target ──────────────────────────────
10|          .-""""-.
  |         /        \
  |        /          `---.________________  Speed
  |       /
  |      /
  |_____/
  +---------------------------------------> 时间
```

**合格标准**：
- 上升时间短（100-300ms 内到达目标）
- 超调 < 20%（峰值不超过目标 1.2 倍）
- 稳态误差 < 5%
- 无持续振荡

### 异常波形诊断表

| 波形现象 | 原因 | 解决 |
|---|---|---|
| Speed 曲线跟不上 Target, 上升缓慢 | Kp 太小, 驱动力不足 | 加大 Kp |
| Speed 快速冲到 Target 上方再回落，反复多次 | Kp 太大, 振荡 | 减小 Kp |
| Speed 超过 Target 后缓慢回落 | 超调大, 阻尼不足 | 加大 Kd |
| Speed 稳定后始终低于 Target | 稳态误差 | 加大 Ki |
| Speed 稳定后一直在 Target 附近小幅抖动 | Ki 过大, 积分振荡 | 减小 Ki |
| Speed 有规律上下摆动（正弦状） | 临界振荡, Kp 过大 | 减小 Kp |
| motor l/-停止后 Speed 曲线不归零 | 编码器读数异常 | 检查编码器共地 |
| PID Out 曲线顶部被削平 (±999) | PID 输出饱和 | 正常现象, 需确认是否影响响应速度 |
| Speed 反复过零摆动 | Kp 过小 + Ki 过大组合, 系统不稳定 | 先调大 Kp 压住振荡, 再调 Ki |

### 施加阻力时的预期

用手指轻捏电机输出轴（施加负载）：
- Speed 曲线出现一个**小凹坑**后迅速回升
- PID Out 曲线同步出现一个**尖峰**（自动加大输出来对抗负载）
- 松手后 Speed 有一个**小凸起**然后恢复

如果 Speed 掉下去回不来 → Ki 不够大。

## 6. 注意事项

1. **VOFA+ 开启时不要发文本调试命令**（`pid l on`），两者互斥但 FireWater 会自动过滤非数字行
2. **调参过程中电机可能剧烈振荡**，手不要靠近旋转部件
3. **供电电压影响**：当前 MG513 额定 12V，如用 7.4V 供电，最大转速会打折扣（约标称 60%），不影响 PID 参数有效性
4. **左右电机参数通常不同**：电机个体差异 + 负载不对称，必须独立调参
5. **调好后记录最终参数**，填入 `Mod_Motor.c` 中 `Pid_Init` 的默认值，掉电不丢
6. **VOFA+ 采样率 200Hz**（5ms 周期），如需降低 CPU 占用可改为在 `Task_Uart_Rx` 中降频发送
