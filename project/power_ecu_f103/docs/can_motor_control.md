# CAN 电机控制帧说明

## 帧格式

| 参数 | 值 |
|---|---|
| CAN ID (hex) | `04480800` |
| 帧类型 | 29-bit 扩展帧 |
| DLC | 8 |
| 目标 | 左电机（MODE_ID_CTRL_LF = 0x020） |

## Data 布局（8 字节，小端序）

| 字节 | 字段 | 类型 | 说明 |
|---|---|---|---|
| 0-1 | speed_enc | int16_t LE | 目标转速（rpm × 10），正数正转、负数反转 |
| 2-3 | angle_enc | int16_t LE | 目标角度（° × 10），当前未使用，填 0 |
| 4-7 | reserved | — | 保留，填 0 |

## 常用转速帧表

### 正转

| 目标 rpm | speed_enc | Data (hex) |
|---|---|---|
| 50 | 500 | `F4 01 00 00 00 00 00 00` |
| 100 | 1000 | `E8 03 00 00 00 00 00 00` |
| 150 | 1500 | `DC 05 00 00 00 00 00 00` |
| 200 | 2000 | `D0 07 00 00 00 00 00 00` |

### 反转

| 目标 rpm | speed_enc | Data (hex) |
|---|---|---|
| -50 | -500 | `0C FE 00 00 00 00 00 00` |
| -100 | -1000 | `18 FC 00 00 00 00 00 00` |
| -150 | -1500 | `24 FA 00 00 00 00 00 00` |
| -200 | -2000 | `30 F8 00 00 00 00 00 00` |

### 刹车

| 功能 | speed_enc | Data (hex) |
|---|---|---|
| 刹车 | 0 | `00 00 00 00 00 00 00 00` |

## 计算方式

`speed_enc` 是 `int16_t`，小端序存储：

```
实际 rpm = speed_enc ÷ 10

例：要发 50 rpm → speed_enc = 500 → hex = 0x01F4 → Data = F4 01
例：要发 -50 rpm → speed_enc = -500 → hex = 0xFE0C → Data = 0C FE
```

## 上位机发送示例

**cangaroo / 通用 CAN 工具：**

```
ID: 04480800 (hex, 29-bit 扩展帧)
Data: F4 01 00 00 00 00 00 00   ← 50 rpm 正转
```

**CAN 分析仪终端命令（示例）：**

```
# 正转 50 rpm
send 04480800#F401000000000000

# 正转 100 rpm
send 04480800#E803000000000000

# 反转 50 rpm
send 04480800#0CFE000000000000

# 刹车
send 04480800#0000000000000000
```

## 验证

下位机收到后串口回显：

```
CAN L:500     ← speed_enc = 500，即 50 rpm
```

用 `status l` 确认：

```
L spd:xxx/500 ang:xxx st:xx   ← target 为 500，解析正确
```
