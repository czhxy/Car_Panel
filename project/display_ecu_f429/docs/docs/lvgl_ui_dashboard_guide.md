## 3. 图像导出

### 3.1 导出为 PNG/JPG

**步骤 4：选择导出元素**

1. 选中要导出的组件/画板
2. 右侧属性面板点击 "Export" 区域
3. 选择导出格式：

| 格式 | 用途 | 建议 |
|------|------|------|
| PNG | 图标、透明度图像 | 背景透明的元素 |
| JPG | 照片、背景图 | 有背景的图像 |
| SVG | 矢量图形 | 简单图形 |

4. 设置分辨率倍数：
   - `@1x` = 原始尺寸
   - `@2x` = 2倍尺寸（Retina屏）
   - 对于 240x320 屏幕，建议使用 `@1x`

**预期结果**：导出 PNG/JPG 文件

```
导出设置：
- Format: PNG
- Suffix: _48px
- 建议尺寸: 24x24, 32x32, 48x48
```

**预期结果**：获得一套统一尺寸的图标

## 4. LVGL 图像转换

### 4.1 LVGL 支持的图像格式

| 格式 | 说明 | 适用场景 |
|------|------|----------|
| C Array | LVGL原生格式 | 所有图像 |
| PNG/JPG | 运行时解码 | 需要节省Flash |
| SVG | 矢量图形 | 简单图形 |

### 4.2 在线转换工具（推荐新手）

**步骤 6：使用 LVGL 官方在线转换器**

1. 访问：https://lvgl.io/tools/image-converter
2. 设置转换参数：

```
Image Input:
- 选择你的 PNG/JPG 文件

Color format:
- 色彩深度: 16bit (RGB565)  ← 推荐
- 或: 8bit (索引色)
- 或: 1bit (单色)

Output format:
- C array  ← 选择这个
- Binary file

Settings:
- Opacity: None 或 Alpha byte
- Browse: None 或 Flip horizontal/vertical
```

3. 点击 "Convert"
4. 点击 "Download" 下载 `.c` 文件

**预期结果**：下载 LVGL 格式的 C 数组文件

---

### 4.3 Python 脚本转换（推荐开发者）

**步骤 7：使用 lv_img_conv.py**

LVGL 提供 Python 转换脚本，位于：
```
third_lib/LVGL/lvgl/tools/lv_img_conv.py
```

**安装依赖：**
```bash
pip install Pillow numpy
```

**使用示例：**
```bash
# 转换单个图像
python lv_img_conv.py input.png --format C_ARRAY --color-format RGB565 -o output.c

# 批量转换
python lv_img_conv.py *.png --format C_ARRAY --color-format RGB565 -o output_folder/
```

**Python 脚本转换代码示例：**
```python
#!/usr/bin/env python3
"""批量转换图像为LVGL格式"""
import os
import sys
from PIL import Image

def convert_to_lvgl(input_path, output_path, width=None, height=None):
    """转换图像为LVGL C数组格式"""
    img = Image.open(input_path)
    
    # 调整尺寸（如果需要）
    if width and height:
        img = img.resize((width, height), Image.LANCZOS)
    
    # 转换为RGB565格式
    img = img.convert('RGB')
    
    # 生成C数组
    pixels = list(img.getdata())
    
    with open(output_path, 'w') as f:
        f.write('/* Generated by LVGL Image Converter */\n')
        f.write('#include "lvgl.h"\n\n')
        f.write(f'const LV_ATTRIBUTE_LARGE_CONST uint8_t img_data[] = {{\n')
        
        for i, (r, g, b) in enumerate(pixels):
            # RGB565 编码
            rgb565 = ((r & 0xF8) << 8) | ((g & 0xFC) << 3) | ((b & 0xF8) >> 3)
            if i % 16 == 0:
                f.write('\n    ')
            f.write(f'0x{(rgb565 >> 8) & 0xFF:02X}, 0x{rgb565 & 0xFF:02X}, ')
        
        f.write('\n};\n')
        
        # 图像描述符
        w, h = img.size
        f.write(f'\nconst lv_img_dsc_t img_{os.path.splitext(os.path.basename(input_path))[0]} = {{\n')
        f.write(f'    .header.always_zero = 0,\n')
        f.write(f'    .header.w = {w},\n')
        f.write(f'    .header.h = {h},\n')
        f.write(f'    .data_size = {len(pixels) * 2},\n')
        f.write(f'    .header.cf = LV_IMG_CF_RGB565,\n')
        f.write(f'    .data = img_data,\n')
        f.write('};\n')

# 使用示例
convert_to_lvgl('icon_speed.png', 'icon_speed.c', width=48, height=48)
```

**预期结果**：生成 `.c` 文件，可直接加入工程

---

### 4.4 色彩格式选择

| 格式 | 大小 | 质量 | 用途 |
|------|------|------|------|
| RGB565 | 2 bytes/pixel | 65K色 | **推荐** 平衡大小和质量 |
| RGB888 | 3 bytes/pixel | 16M色 | 高质量，但占用大 |
| Alpha8 | 1 byte/pixel | 灰度+Alpha | 图标遮罩 |
| ALPHA | 1 byte/pixel | 只有透明度 | 需要自定义着色 |

## 5. LVGL 集成

### 5.1 添加图像到工程

**步骤 8：组织图像文件**

在 `app/` 或 `task/` 目录下创建图像资源：

```
app/
├── img/
│   ├── img_speed_gauge.c      # 仪表盘背景
│   ├── img_speed_needle.c     # 速度指针
│   ├── img_battery.c          # 电量图标
│   ├── img_warning.c          # 警告图标
│   └── img_arrow.c            # 方向箭头
```

**预期结果**：图像资源文件添加到项目

---

### 5.2 声明图像

**步骤 9：创建图像头文件**

```c
/* app/img/resources.h */
#ifndef _APP_IMG_RESOURCES_H_
#define _APP_IMG_RESOURCES_H_

#include "lvgl.h"

/* 声明所有图像 */
extern const lv_img_dsc_t img_speed_gauge;
extern const lv_img_dsc_t img_speed_needle;
extern const lv_img_dsc_t img_battery;
extern const lv_img_dsc_t img_warning;
extern const lv_img_dsc_t img_arrow_up;
extern const lv_img_dsc_t img_arrow_down;

#endif
```

**预期结果**：统一的图像资源接口

---

### 5.3 使用图像

**步骤 10：在 LVGL 中显示图像**

```c
#include "resources.h"

/* 创建图像控件 */
lv_obj_t * img_speed = lv_img_create(parent);
lv_img_set_src(img_speed, &img_speed_gauge);
lv_obj_align(img_speed, LV_ALIGN_CENTER, 0, 0);

/* 旋转指针 */
lv_img_set_angle(img_speed_needle, 1800);  // 0.1度单位，1800 = 180度

/* 动态更新 */
lv_img_set_angle(img_speed_needle, speed * 18);  // 速度0-100对应0-180度
```

**预期结果**：图像正确显示在屏幕上

---

### 5.4 图像按钮示例

```c
/* 创建图像按钮 */
lv_obj_t * btn = lv_btn_create(parent);
lv_obj_set_size(btn, 48, 48);

lv_obj_t * img = lv_img_create(btn);
lv_img_set_src(img, &img_arrow_up);

```

## 9. 常见问题

**Q: 图像显示颜色异常？**
A: 检查 LVGL 色彩格式设置，尝试切换 RGB565 字节序

**Q: 图像占用Flash太大？**
A: 使用索引色(8bit)或单色(1bit)，或压缩PNG后转换

**Q: 如何更新动态元素？**
A: 使用 lv_img_set_angle() 旋转指针，lv_img_set_zoom() 缩放

**Q: 支持触摸交互吗？**
A: 是的，使用 lv_btn 或 lv_imgbtn 包裹图像控件
